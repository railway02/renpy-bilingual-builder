# Bundled license sources

- Roboto: https://github.com/googlefonts/roboto/blob/main/LICENSE (Apache 2.0).
- Tcl 8.6: https://github.com/tcltk/tcl/blob/core-8-6-15/license.terms.
- Tk 8.6: https://github.com/tcltk/tk/blob/core-8-6-15/license.terms.

These are unmodified upstream license texts. Tcl/Tk copies are fallbacks for
CPython installers that do not include their separate license files.
Other component licenses are collected from installed distribution metadata.
