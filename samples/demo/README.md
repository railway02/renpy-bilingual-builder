# 不含游戏资源的演示

此目录里的对白是为本工具编写的独立示例，用于体验构建、运行测试和报告问题。

- `chinese/`：中文翻译，含原文注释。
- `spanish/`：同一原文的西班牙语翻译。
- `original/`：对应的原文脚本；有原文注释时可以不选它。

在 GUI 中点击“载入演示”，或选择 `chinese/` 为翻译目录，再点击构建。
输出应包含 4 条双语对白；`strings` 中的菜单翻译保持原样。
若选择 `spanish/`，会自动识别为 `spanish`，同样不依赖文件名是 `script.rpy`。

这些文件用于工具演示，不应部署到你正在游玩的其他游戏。
